# hxwl-12 会谈预约与改期额度台

心理咨询会谈的预约、改期额度与版本管理原型。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 功能规则

- **预约单**：填写来访者代号、咨询师、形式（面询/视频/语音）与起止时刻。
- **冲突拦截**：同一咨询师同一时段只接受一场会谈；同一来访者相邻两场之间留 15 分钟缓冲。相撞时保留已填内容，并列出冲突预约（来访者、咨询师、冲突时段、命中的规则）。
- **改期额度**：每位来访者每月 2 次免费改期；用完后须指定督导并填写理由，缺任一项则改期不生效，原时段继续占用、不释放给他人。
- **冻结与版本**：会谈确认后预约冻结，更正不改写历史，另存为带原因的新版本，版本历史可展开查看。
- **持久化**：预约、改期额度与版本记录保存在 localStorage，刷新后保持一致。
