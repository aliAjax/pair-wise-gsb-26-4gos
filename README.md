# hxwl-12 会谈预约与改期额度台

心理咨询会谈预约、冲突检测、改期额度与冻结更正版本管理

## 技术栈

React + Vite + TypeScript + CSS（localStorage 持久化）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 业务规则

- **预约单**：来访者代号、咨询师、形式（面谈 / 视频 / 电话）、起止时刻，缺一不受理但保留已填内容。
- **规则① 咨询师时段唯一**：同一咨询师同一时段只接受一场会谈。
- **规则② 来访者 15 分钟缓冲**：同一来访者相邻两场会谈之间至少间隔 15 分钟，且不能时间重叠。
- **规则③④ 改期额度**：每位来访者每月两次免费改期；用完后改期必须同时指定督导并写理由，缺任一项时原时段继续占用、不释放给他人。
- **规则⑤ 冻结更正**：会谈确认后预约冻结，任何更正另存为带原因的新版本，完整保留版本链。
- **冲突提示**：受阻时列出来访者、咨询师、申请 / 冲突时段、冲突预约单号与命中的规则。
- **持久化**：预约、改期额度与版本存入 localStorage，刷新页面后保持一致。
